## Description
Some tools for transform standard python scripts in NumWorks python scripts by changing:
- Indentation
- Comments
- Line break
- Spaces between operators
- Etc.
## Installation
```bash
git clone https://github.com/gradient01/compact-numworks-scripts.git
```
Then, change `INPUT_PATH` and `OUTPUT_PATH` in `main.py` with your file paths.  
```bash
python3 main.py
```
